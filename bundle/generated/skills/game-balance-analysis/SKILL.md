# game-balance-analysis

## 目的
意味、適用範囲、維持する定性的関係が確定したゲームルールと定量的な問いから、ゲームプレイ上の関係が成立する数値範囲、破綻条件、感度、数値候補またはルール式候補を分析する。

成果は、変数、単位、仮定、時間幅、戦略またはシナリオ、計算方法、結果、不確実性を追跡できる定量モデルと分析結果である。

## 責務
このスキルは、次の定量判断を所有する。

- ゲーム状態とルールを、単位と時間幅を持つ変数、式、遷移、確率分布へ写す。
- 状態量の流入、流出、保持、累積、減衰と、失敗または回復へ至る遷移が成立する範囲を調べる。
- 同じ状態、利用可能な情報、目的、時間幅で戦略を比較し、支配条件と有効条件を識別する。
- 分散、極端条件、累積効果、複利効果が結論を変える条件を調べる。
- 入力値の変化が結果へ与える影響と、結論が変わる境界を感度として示す。
- 成立範囲内の数値、相対関係、ルール式の候補、または成立範囲が空であることと再検討するルール条件を返す。

確認済みのルール意味、体験目標、プレイヤーが利用できる情報を入力として受け取り、定量モデル、成立範囲、感度、破綻条件を成果として返す。体験設計、ルール意味、プレイヤー反応は、それぞれを確定した成果から受け取る。数値、相対関係、ルール式の候補は状態 `提案` とし、採用権限を持つ主体が採用状態を決める。

## 入力契約
次を入力として受け取る。

- 定量的に答えるゲーム設計上の問いと、結果によって変わる設計判断。
- 意味と適用範囲が確定したルール、状態、行為、結果、状態遷移、初期条件、および固定済みの部分と変更を許された変数。
- 意図する相対関係と、維持する定性的関係。確定している場合は、目標状態、許容範囲、閾値が区別する結果の意味、失敗または回復の条件。
- 分析する時間幅と、比較する戦略、プレイ方針、シナリオ。
- プレイヤーが各判断で利用できる情報。
- 観測値、確認済みの値、仮定値、導出値と、それぞれの地位、適用範囲、根拠。
- 分析へ使える計算環境、データ、実行時間などの制約。

割合または点数を定量目標として使う場合は、測定対象、単位、導出方法、許容範囲も入力として受け取る。

## 開始状態
入力の成立状態から次を選ぶ。

| 状態 | 到達条件 | 成果 |
| --- | --- | --- |
| `分析開始` | 定量的な問い、結果が変える設計判断、ルールの意味と適用範囲、維持する定性的関係、比較条件、入力値の地位、目標または許容範囲を追える。 | 目標への成立範囲を分析する。 |
| `シナリオ比較` | 目標または許容範囲が未確定で、比較する前提またはシナリオを追える。 | 前提ごとの結果と、目標判断に必要な差を返す。 |
| `入力不足` | ルール意味、体験目標、プレイヤー観測、対象、単位、比較条件のいずれかが、問いまたは結論を変える状態で不足または競合する。 | 欠けている入力と、影響するモデルまたは結論を返す。 |

測定契約が不足した割合または点数は `未定義の数値表現` として分離し、測定対象、単位、導出方法、許容範囲を不足入力として返す。定量モデルには、成立した入力だけを使う。

## フロー

### Phase 1: 入力を定量モデルへ写す
対象となる状態、プレイヤーが利用できる情報、目的、時間幅、戦略またはシナリオをモデル境界として固定する。

変数ごとに名称、意味、単位、範囲、初期値、更新契機を定める。入力値を次の地位へ分類する。

| 地位 | 意味 |
| --- | --- |
| 観測値 | 指定した条件と範囲で観測された値。 |
| 確認済み値 | 採用権限を持つ主体または正本が確定した値。 |
| 仮定値 | シナリオまたは分析のために置いた値。暫定実装値も適用範囲付きでここへ置く。 |
| 導出値 | ほかの入力と式から求めた値。 |

モデルへ含める状態、遷移、確率、時間幅と、モデル境界外の要因を示す。比較は共通の単位と時間幅、または明示した換算規則で行う。

定量的な問いを識別するための表現を `分析モデル` とする。分析モデルは、ゲームへ採用するルールそのものとは限らない。確認済みの状態、行為、結果の意味、適用範囲、定性的関係を算術へ写す候補を `ルール式候補` とし、状態 `提案` で扱う。状態、行為、状態遷移、利用可能な情報、目的、結果の意味、定性的関係の追加または変更が必要な場合は、ルール式を補完せず、必要なゲーム設計上の判断と影響範囲を返す。

### Phase 2: 必要な分析方法を選ぶ
設計判断を変える差を先に特定し、その差を識別できる最も単純な分析モデルと方法を、閉形式の計算、表計算、列挙、シミュレーション、感度分析から選ぶ。分析モデルへ項または補正を加える場合は、その追加が区別する状態または関係を示す。問いの識別に寄与しない項は加えない。必要な精度は、問いの許容範囲と結論が変わる境界から決める。

同じ入力から同じ結果を再現できるよう、式、計算順序、乱数条件、反復回数など、選んだ方法に必要な再現条件を残す。

### Phase 3: 戦略と成立範囲を分析する
選んだ方法で計算またはシミュレーションを実行し、対象に関係する観点を比較する。

| 観点 | 判断 |
| --- | --- |
| 状態量の変化 | 値の流入、流出、保持、累積、減衰が、対象期間で意図した状態差を作るか。 |
| 戦略比較 | 同じ情報、目的、状態、時間幅で、状況に応じた有効戦略が分かれるか。 |
| 支配条件 | 一つの選択が常に有利になる条件と、ほかの選択が有効になる条件は何か。 |
| 失敗と回復 | 意図した失敗状態から、許された手段と期間で再び有効な選択肢へ到達できるか。 |
| 時間による変化 | 状態、利用可能な選択、費用、効果の累積が、意図した時期に判断や活動を変えるか。 |
| ばらつき | 分散、極端条件、累積効果、複利効果が、平均値から得る結論をどう変えるか。 |
| 感度 | 入力の変化で結論が反転する境界と、結論が安定する範囲は何か。 |

入力範囲がある場合は、基準、下限側、上限側、極端条件、結論が反転する境界のうち、問いを識別するために必要なシナリオを比較する。

### Phase 4: 結果の状態を判断する
分析結果を次の状態へ分類する。

| 結果状態 | 到達条件 | 成果 |
| --- | --- | --- |
| `成立範囲あり` | 意図する関係または目標を満たす範囲がある。 | 成立範囲、前提、範囲外の破綻、異なる範囲が生むプレイ上の差を返す。 |
| `成立範囲なし` | 入力契約のルール関係では成立範囲が空集合である。 | 調整を停止し、成立を妨げるルールまたは関係を返す。 |
| `目標未確定` | シナリオ比較を完了し、採否を決める目標または許容範囲が未確定である。 | シナリオごとの結果と、必要な目標判断を返す。 |

成立範囲から得た数値、相対関係、ルール式の候補は、状態 `提案`、成立条件、感度、予測される影響を付けて返す。ルール式候補には、それが保持する状態、行為、結果の意味、適用範囲、定性的関係を対応させる。意味または定性的関係の変更が必要な場合は候補状態を付けず、再判断が必要なゲーム設計上の問いとして返す。

## 成果契約
`入力不足` では、欠けている入力と、影響するモデルまたは結論を返す。

定量モデルと分析結果では、依頼に必要な項目を次から選ぶ。

- 分析上の問いと、結果によって変わる設計判断。
- 開始状態と結果状態。
- 対象範囲、時間幅、戦略、シナリオ。
- 変数、単位、状態遷移、確率分布、および分析モデルで使用した式。
- 観測値、確認済み値、仮定値、導出値と根拠。
- 使用した方法と再現条件。
- 戦略比較、支配条件、成立範囲、破綻条件、回復条件。
- 感度と結論が安定する範囲。
- 状態 `提案` の数値、相対関係、ルール式候補と、成立条件、感度、予測される影響。ルール式候補を返す場合は、それが保持する状態、行為、結果の意味、適用範囲、定性的関係。
- モデル境界外の要因、残る不確実性、必要なゲーム設計上の判断。

比較を表で示す場合は、必要な列を使う。

| シナリオまたは戦略 | 前提 | 結果 | 成立条件 | 破綻条件 | 感度 | 設計上の含意 |
| --- | --- | --- | --- | --- | --- | --- |

## 完了条件
共通して、開始状態が `分析開始 / シナリオ比較 / 入力不足` のいずれかに定まり、状態に対応する成果がある。

`入力不足` では、次を満たす。

- 欠けている入力と、影響するモデルまたは結論を追える。
- `未定義の数値表現` がある場合は、必要な測定対象、単位、導出方法、許容範囲を追える。

`分析開始` または `シナリオ比較` では、次を満たす。

- 分析上の問い、対象範囲、時間幅、比較条件を追える。
- 変数、単位、入力値の地位、式または状態遷移を追える。
- ルール式候補を返す場合は、分析モデルで使用した式と、ゲームへ採用を提案する式を区別できる。
- 選んだ分析方法と再現条件を追える。
- 結果を、意図するゲーム設計上の関係または未確定の目標判断へ追跡できる。
- 問いに必要な成立範囲、破綻条件、感度、支配条件、回復条件が示されている。
- 各入力値が観測値、確認済み値、仮定値、導出値のいずれかに対応する。
- 数値、相対関係、ルール式の候補を返す場合は、状態 `提案`、成立条件、感度、予測される影響を持つ。ルール式候補は、保持する状態、行為、結果の意味、適用範囲、定性的関係を追える。
- 成果が定量モデル、分析結果、モデル境界外の要因、残る不確実性で構成されている。

`分析開始` では、結果状態が `成立範囲あり / 成立範囲なし` のいずれかに定まる。`シナリオ比較` では、結果状態が `目標未確定` に定まり、目標判断に必要な差を追える。
