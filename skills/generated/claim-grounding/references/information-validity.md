# 情報としての利用可能性

## 適用条件
次の情報を下流作業で利用する前に、根拠、適用範囲、再評価条件を確定する必要がある場合に使う。

- 成果物の更新とは独立して値または真偽が変化する情報。
- 外部の正本、実行環境、データから観測または導出する情報。
- 集計、スナップショット、予測、推定。
- 複数の資料で対象範囲または有効範囲が異なる情報。

## 判断軸

| 軸 | 確認内容 |
| --- | --- |
| 成立方式 | 定義または規則、観測、導出、予測または推定のどれか。 |
| 根拠と責任 | 値または真偽を定める正本、観測主体、算出主体と、根拠が証明できる範囲。 |
| 適用範囲 | 版、対象、地域、期間、環境、データ範囲、シナリオ、実行個体のうち、利用可否を変えるもの。 |
| 評価時点 | 観測、取得、算出、予測を行った時点。 |
| 変化契機 | どの変更、事象、経過、再実行によって再評価が必要になるか。 |
| 更新または評価方法 | 正本として維持、外部変更へ同期、固定した観測として保存、利用時に取得または再計算のどれか。 |

適用範囲には、その違いによって情報の利用可否または下流の判断が変わる項目を残す。

## 情報状態

| 状態 | 基準 |
| --- | --- |
| `利用可能` | 指定した利用目的について、根拠、責任主体、適用範囲、必要な評価時点または再評価条件を確認できる。 |
| `要再評価` | 変化契機が発生した、適用範囲を外れた、または必要な時点で利用可能か再確認する必要がある。 |
| `競合` | 同じ範囲について両立しない根拠があり、責任主体または優先関係を確定できない。 |
| `未確認` | 根拠、責任主体、適用範囲、評価時点、算出方法のうち、指定用途の判断に必要な情報が不足している。 |
| `対象外` | 利用目的上、情報としての利用可能性を判断する必要がない。 |

`利用可能` には、判断に使った目的と適用範囲を対応させる。

## 判断規則
- 成果物が所有する定義または規則と、外部の正本や実行時状態から決まる値を区別する。
- 観測値と導出値は、根拠、評価時点、適用範囲、必要な算出方法へ追跡できる場合だけ `利用可能` にする。
- 固定した観測は、その時点と範囲を持つ記録として扱い、現在値を定める責務は確認した正本へ対応させる。
- 予測と推定は、対象期間またはシナリオ、根拠、算出方法、不確実性を保持する。
- 外部の正本が独立して更新される場合は、正本を参照する、外部変更へ同期する、利用時に取得または再計算する、のどれによって利用可能性を維持するか確認する。
- 複数の根拠が衝突する場合は、値を定める責任主体と適用範囲から優先関係を決める。更新日時は、更新または置換候補の探索に使う。
- 情報源、算出方法、適用範囲の確認が不足する場合は、変化契機の有無に応じて `未確認` または `要再評価` とし、確認事項を残す。
- 採用状態は方針または契約上の採否を定める根拠から判断し、情報状態は指定用途での利用可能性を定める根拠から判断する。
