# 会話と資料における採用状態

## 適用条件
提案、決定、指示、質問、回答、例示、訂正、撤回、採用、不採用、置換が混在し、下流作業で使う命題の現在の地位を確定する必要がある場合に使う。

## 独立して判断する軸

| 軸 | 確認内容 |
| --- | --- |
| 主体 | 実際に発言または記述した主体。 |
| 発話機能 | 主張、決定、指示、提案、質問、回答、例示、訂正、理由説明、観測報告、推論のうち、発言が実際に果たす機能。 |
| 権限 | その主体が、対象命題のどの範囲を決定できるか。 |
| 根拠の役割 | 期待を定める、既存契約を示す、現状を示す、検討材料、説明・例示、導出、未確認のうち、何の判断を支えられるか。 |
| 対象 | 回答、採用、不採用、訂正、置換、撤回が作用する命題。 |

権限、発話機能、根拠の役割は、それぞれを示す根拠から判断する。同じ発言が訂正と決定を兼ねる場合などは、必要な発話機能を複数記録する。

## 採用状態

| 状態 | 基準 |
| --- | --- |
| `採用済み` | 対象範囲の決定権限を持つ主体が採用または決定した、または認められた現在の契約が定めている。 |
| `未決定` | 決定権限を持つ主体が、判断対象そのものを現在も未決定であると明示している。 |
| `不採用` | 決定権限を持つ主体が、対象候補を採用しないと明示している。 |
| `置換済み` | 同じ範囲を扱う後続の採用済み命題によって、明示的に訂正または置換されている。 |
| `競合` | 同じ範囲について両立しない権限ある決定または契約があり、優先関係を確定できない。 |
| `未確認` | 採否、権限、対象、範囲を確定する根拠が不足している。 |
| `対象外` | 例示、質問、背景説明など、採否を定める用途ではない。 |

## 判断手順
最初に、認められた既存契約と、決定権限、対象、適用範囲が一致する明示的な決定、回答、採用、不採用、訂正を確認する。
次に、各根拠が支えられる状態を次の表で決める。

| 確認できた根拠 | 結果 |
| --- | --- |
| 決定権限、対象、適用範囲が一致する明示的な採用または現在の契約 | 対象命題を `採用済み` とする。 |
| 決定権限を持つ主体が、判断対象そのものを未決定と明示している | 明示された判断対象を `未決定` とする。個別提案の採否は、それぞれを対象とする根拠で判断する。 |
| 決定権限、対象、適用範囲が一致する明示的な不採用 | 対象候補を `不採用` とする。 |
| 採用済みの命題を対象とする明示的な訂正、撤回、置換 | 対象と範囲が一致する先行命題を `置換済み` とし、後続命題の状態をその根拠から決める。 |
| 同じ範囲について両立しない権限ある決定または契約 | 優先関係を確定できるまで `競合` とする。 |
| 提案、レビュー所見、沈黙、反対がなかったこと | 採否を判断する必要がある候補は `未確認` とする。 |
| 例示、質問、背景説明 | 採否を定める用途では `対象外` とする。 |
| 正本からの欠落、または成果物責務に基づく削除 | 配置または記載状態を示す根拠として扱い、採否は対象を明示する根拠から判断する。採否の根拠が揃うまでは `未確認` とする。 |
| 別の主体による要約または引用 | 確認できる元発言を状態判断の根拠にする。元発言を確認できるまで `未確認` とする。 |
| 確認済みの前提から必然的に導かれる推論 | 前提の採用状態、対象、範囲、確度を保持して結論を扱う。必然性または前提を確認できるまで `未確認` とする。 |

発言の新しさは訂正、撤回、置換の候補を探索する順序に使う。状態の更新は、発話機能、決定権限、対象、適用範囲を確認して行う。

採用状態は、命題の方針または契約上の地位を表す。外部の事実として利用できる範囲は、`information-validity.md` で情報状態として判断する。
