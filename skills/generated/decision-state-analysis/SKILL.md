# decision-state-analysis

## 目的
一つ以上の会話、回答、議事録、仕様、判断履歴、未決事項などから、複数の発言または命題について、決定論点と決定候補を分け、基準時点での決定状態を根拠付きで復元する。

成果は、決定論点の解消済み、未決、判定不能と、決定候補の決定済み、提案中、却下済み、上書き済み、判定不能を分け、質問、仮説、観測、導出結果との関係を追跡できる決定状態表である。

このスキルは、案の良否や採否を新たに決めず、文章、仕様、Issue、実装を更新しない。

## 基準時点
このスキルで使う「現在」「現在有効」「現在状態」は、指定した基準時点における状態を指す。

- 決定論点、決定候補、質問、導出結果を、基準時点で状態を判定する対象とする。仮説と観測には基準時点での状態を与えず、記録が明示する対象時点を保持する。
- 基準時点は、根拠が届く時点へ都合よく移動せず、依頼が求める状態の時点から決める。明示された時点を最優先し、「現在」または「現在有効」を求める依頼では分析開始時点、対象を限定した会話や判断履歴の終了時点を求める依頼では対象範囲内で明示された最新の対象時点または発効時点を使う。記録の作成時点だけから対象時点を推定しない。
- 依頼目的から基準時点を一意に選べない場合は、候補を任意に選ばず、求める状態の時点を最小限の確認事項として返し、状態判定を開始しない。
- 異なる基準時点を必要とする対象群または期間があり、命題間の関係を壊さず独立して評価できる場合だけ、対象範囲または期間を分ける。単一の基準時点が明示されている場合や、分割すると関係を失う場合は対象を一つに保ち、その基準時点まで根拠が届かない行を判定不能として残す。
- 状態を判定する各対象について、根拠または有効性の継続を保証する契約が基準時点まで届くかを確認する。基準時点までに空白期間があり、その間の有効性を確認できない場合は、変更がないと仮定せず、判定不能と確認事項として残す。
- 仮説または観測を他の命題の根拠にする場合は、その仮説または観測を基準時点まで継続する状態として扱わず、根拠先の命題について、その対象時点の内容が基準時点での状態を支えられるかを判定する。
- 基準時点より後に成立した決定は、基準時点の状態を上書きする根拠にしない。必要な場合は、基準時点後の履歴として分ける。
- 基準時点より後に作られた記録は、その作成時点と記録が明示する対象時点を分ける。決定の正本など、基準時点の状態を遡って証明する責務と権限を確認できる場合だけ、基準時点の根拠として使う。

## 扱う単位
記録に含まれる内容を、次の役割に分ける。

| 役割 | 基準 |
| --- | --- |
| `決定論点` | 選択、方針、規則、優先順位、対象範囲などについて、権限を持つ主体の判断を必要とする対象と条件。 |
| `決定候補` | 決定論点に対して、採用、却下、または変更の対象となる具体的な内容。 |
| `質問` | 判断または情報を求める命題。 |
| `仮説` | 真偽、効果、成立可能性を観測または検証する必要がある命題。 |
| `観測` | 起きた事象、現在の状態、測定結果などを報告する命題。 |
| `導出結果` | 有効な決定または契約から、追加の前提や裁量なしに一意に成立する命題。 |

提案、回答、要約、文書、実装は情報の形式であり、それだけで役割や決定状態を定めない。

一つの決定論点に複数の決定候補を対応付けてよい。候補一件の却下だけで論点全体を解消済みにせず、論点と各候補を別の ID で結び付ける。

仮説そのものと、その仮説を作業上の前提として採用する決定候補は別の命題として扱う。導出結果は決定主体が新たに選んだ内容ではないため、独立した決定候補へ昇格させない。

## 状態

### 決定論点
| 状態 | 基準 |
| --- | --- |
| `解消済み` | 対象と条件を満たす一つ以上の決定候補が基準時点で決定済みであり、論点に未決の部分が残っていない。 |
| `未決` | 決定を必要とする論点があるが、対象と条件を満たす決定済みの候補を確認できない。 |
| `判定不能` | 論点の対象、条件、必要な決定範囲、または関係する候補の状態を確定できない。 |

### 決定候補
| 状態 | 基準 |
| --- | --- |
| `決定済み` | 決定主体または決定の正本が、対象と条件を特定して候補を基準時点で有効な内容として明示している。 |
| `提案中` | 候補は示されているが、決定主体による採用または却下を確認できない。 |
| `却下済み` | 決定主体または決定の正本が、候補を採用しないと明示している。 |
| `上書き済み` | 基準時点より前には決定済みだったが、同じ対象と条件について基準時点までに成立した後続の決定へ置き換えられている。 |
| `判定不能` | 対象、条件、決定主体、権限、根拠、優先関係のいずれかが不足または競合し、状態を確定できない。 |

### その他の役割
- 質問には `解消済み / 未解消 / 判定不能` を与え、解消の根拠となる回答、決定、観測へ対応付ける。
- 導出結果には `成立 / 不成立 / 判定不能` を与え、根拠となる有効な決定または契約をすべて対応付ける。
- 仮説と観測には状態を与えず、決定状態表の状態欄を `適用なし` とする。これらを前提として採用する決定がある場合は、別の決定候補として置く。

複数の妥当な選択肢が残る推論、新しい前提を必要とする推論、案の良否を含む推論は、導出結果として成立させない。

## フロー

### Phase 1: 対象と根拠を固定する
- 棚卸しする対象範囲と、依頼が求める状態の時点を確認する。
- 基準時点は、明示された時点、現在状態を求める依頼の分析開始時点、限定された会話または判断履歴の終了時点を求める依頼の順に、依頼目的と対象範囲から一意に確定する。履歴の終了時点は、明示された最新の対象時点または発効時点から決め、記録の作成時点だけで代用しない。一意に確定できない場合は、状態判定を開始せず確認する。
- 異なる基準時点を必要とする独立した対象群または期間がある場合だけ、命題間の関係を壊さない単位へ分ける。分割できない場合、または単一の基準時点が明示されている場合は対象を一つに保ち、その基準時点まで根拠が届かない行を判定不能とする。
- 利用する会話、回答、議事録、仕様、判断履歴、未決事項、関連する契約を列挙する。
- 各記録について、作成時点、明示された対象時点、発言または記録の主体と、その記録が決定、根拠、現状、履歴のどれを所有するかを確認する。
- 状態を判定する各対象について、最後に状態を確認できる時点と、有効性の継続を保証する契約がある場合はその期間を確認し、基準時点までの証拠範囲を明らかにする。
- 仮説と観測については、記録が明示する対象時点を確認する。他の命題の根拠に使う場合は、根拠先の命題の状態判定において時間的な妥当性を確認する。
- 決定主体と権限は、明示された役割、プロジェクトの契約、成果物の責務から確定する。発言者、文書作成者、実装者であることだけを決定権の根拠にしない。
- 同じ未確認の前提から作られた複数の記録は、独立した根拠として数えない。

### Phase 2: 命題と対応関係を分ける
- 対象、役割、責任主体、条件、前後関係が曖昧な場合は `$referent-modeling` を適用する。
- 一つの記述に複数の対象、条件、質問、選択、結論が含まれる場合は、個別に状態を判定できる命題へ分ける。
- 判断を必要とする決定論点と、その論点に対する各決定候補を分け、別の ID で対応付ける。
- 代名詞、省略された主語、「それでよい」などの応答は、参照先を一意に対応付けられる場合だけ対象へ結び付ける。
- 各命題から出所を追跡できるようにする。

### Phase 3: 役割と根拠を判定する
- 各命題を `決定論点 / 決定候補 / 質問 / 仮説 / 観測 / 導出結果` に分ける。
- 決定主体または決定の正本による明示的な採用、却下、変更だけを決定の根拠とする。
- エージェントや参加者による提案、候補の列挙、確認されていない要約を決定へ昇格させない。
- 現在の文書や実装は、その成果物が決定の正本であると契約で定められていない限り、現状を示す観測として扱う。
- 記録から省かれたこと、一覧から削除されたこと、返答がないこと、異議が示されなかったことを、採用、却下、解消の根拠にしない。
- 有効な決定または契約から裁量を伴わず一意に成立する命題だけを導出結果とし、根拠となる命題を対応付ける。

### Phase 4: 基準時点での状態と関係を復元する
- 状態を判定する対象について、根拠または有効性の継続を保証する契約が基準時点まで届かない場合は、空白期間を示して `判定不能` とする。
- 明示された上書き関係、対象領域で定められた優先規則、同じ決定主体による明確な訂正を確認する。
- 二つの命題が同じ対象と条件について両立しない場合だけ、上書きまたは競合の候補として扱う。
- 根拠となる発言や記録の時点が新しいことだけを上書きの根拠にしない。
- 優先関係を確定できない有効な命題が競合する場合は `判定不能` とする。
- 決定論点は、対応する決定候補が対象と条件をすべて満たす場合だけ `解消済み` とする。候補一件の却下、提案中の候補、または一部の条件だけを満たす決定で論点全体を解消しない。
- 回答は、求められた判断または情報を対象と条件が分かる形で与えている質問だけを `解消済み` にする。
- 一つの質問への回答から、兄弟関係にある別の質問まで解消したと推定しない。
- 一部だけ回答された質問は、回答部分と残りを分け、残りを `未解消` とする。
- 導出結果が成立しても、元の決定とは別の決定が行われたとは扱わない。

### Phase 5: 取りこぼしと誤昇格を監査する
- 対象範囲にあった決定論点、各決定候補、質問が、基準時点での状態へ対応していることを確認する。
- 状態を判定する各対象の証拠範囲が基準時点まで届き、空白期間を無根拠に補っていないことを確認する。
- 仮説と観測に基準時点での状態を与えず、記録が明示する対象時点を保持していることを確認する。
- 各決定論点から関係する決定候補を追跡でき、候補の採否と論点の解消状態が混在していないことを確認する。
- 解消済みの質問から、解消した回答または命題を追跡できることを確認する。
- 未解消の質問が、回答済みの質問と一緒に消えていないことを確認する。
- 提案、仮説、観測、導出結果が、決定主体の明示なしに決定として扱われていないことを確認する。
- 同じ命題を重複して数える場合は統合し、出所と上書き関係は保持する。
- 基準時点で有効な内容、基準時点より前の履歴、基準時点より後の履歴を混在させない。

### Phase 6: 結果を返す
必要な行だけを、次の形式で返す。

対象範囲または期間を分けた場合は、各単位について `対象と前提`、`決定状態表`、必要な `基準時点後の履歴` を一体として繰り返し、単位ごとの基準時点を明示する。各単位に単位 ID を付け、命題の ID は成果全体で一意にし、同じ命題には単位をまたいで同じ ID を使う。状態行は単位 ID と命題 ID の組で識別し、異なる基準時点の状態を一つの表へ混在させない。

#### 対象と前提
- 単位 ID
- 対象範囲
- 基準時点と選択理由
- 利用した根拠
- 決定主体と権限について確認できたこと
- 今回置いた仮定

#### 決定状態表
| ID | 命題 | 役割 | 対象と条件 | 記録主体 | 決定主体 | 基準時点での状態 | 根拠とその役割 | 関係するID | 確認事項 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

#### 監査結果
- 基準時点で有効な決定候補
- 解消済みおよび未決の決定論点
- 提案中、却下済み、または上書き済みの決定候補
- 解消済みおよび未解消の質問
- 仮説、観測、導出結果
- 競合と判定不能事項
- 取りこぼしまたは誤削除の可能性

#### 基準時点後の履歴
基準時点後に初めて成立した内容を履歴として示す必要がある場合だけ、次の表を追加する。

| ID | 記録時点 | 対象または発効時点 | 命題 | 役割 | 根拠 | 関係するID |
| --- | --- | --- | --- | --- | --- | --- |

この表の命題には基準時点での状態を与えない。基準時点より後に作られた記録でも、基準時点以前の状態を遡って証明する責務と権限を確認できるものは、この履歴ではなく決定状態表の根拠へ置く。

上位の作業から利用された場合は、単位 ID、対象と前提、基準時点と選択理由、決定状態表、必要な基準時点後の履歴を一体の単位集合として上位作業へ渡す。このスキルだけで文章、仕様、Issue、実装へ反映しない。

## 確認と停止
依頼目的から基準時点を一意に確定できない場合は、状態を任意の時点で判定せず、求める状態の時点を最小限の確認事項として返して停止する。

次の場合は、決定候補を決定済み、却下済み、上書き済みと確定せず、決定論点または質問を解消済み、導出結果を成立と確定せず、判定不能または未解消として残す。

- 決定主体または必要な権限を確定できない。
- 命題の対象、条件、応答の参照先を一意に対応付けられない。
- 有効な根拠が競合し、優先関係を確定できない。
- 状態を判定する対象について、根拠または有効性の継続を保証する契約が基準時点まで届かない。
- 導出に新しい前提、選好、裁量を必要とする。
- 状態を支える唯一の根拠を確認できない。

棚卸しだけを求められている場合は、判定不能事項と必要な確認を示して結果を返す。判定不能な内容を基準時点で有効な決定として後続作業へ渡す必要がある場合は、その反映を停止し、状態を確定するための最小限の確認を求める。

## 完了条件
- 基準時点とその選択理由を依頼目的から追跡でき、一意に確定できない場合は任意に選ばず確認している。
- 対象範囲の各決定論点、決定候補、質問、導出結果について、根拠から基準時点での状態まで追跡できる。
- 状態を判定する各対象の証拠範囲が基準時点まで届くかを確認し、空白期間を無根拠に補っていない。
- 仮説と観測は記録が明示する対象時点を保持し、基準時点での状態を与えていない。
- 対象範囲または期間を分けた場合は、命題間の関係を保った独立した単位ごとに基準時点と状態表を示し、異なる基準時点を一つの表へ混在させていない。
- 命題 ID は成果全体で一意かつ同じ命題に対して安定しており、各状態行と基準時点後の履歴を単位 ID および命題 ID から追跡できる。
- 上位作業へ渡す場合は、単位 ID、対象と前提、基準時点、決定状態表、必要な履歴を一体の単位集合として保っている。
- 決定論点と各決定候補が別の ID で分かれ、候補の状態と論点の解消状態を混在させていない。
- 決定済みの候補が、決定主体または決定の正本による明示に限られている。
- 質問の解消状態と、それを解消した回答または命題の対応を追跡できる。
- 導出結果を、その根拠となる決定および新しい独立した決定と区別している。
- 未解消の質問、未決の決定論点、提案中、却下済み、上書き済みの決定候補、競合、判定不能が、基準時点で有効な決定候補と分離されている。
- 提案、仮説、観測、導出結果を決定へ昇格させていない。
- 対象、条件、責任主体、根拠を、記録にない内容で補っていない。
- 判定不能事項ごとに、状態を確定するための最小限の確認事項がある。
- 基準時点後に初めて成立した内容を含める場合は、基準時点での状態を付けず、基準時点後の履歴として分けている。
- 案の採否、文章や成果物への配置、レビュー所見への対応を、このスキルで新たに決めていない。
