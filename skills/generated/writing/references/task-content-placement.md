# 内容の責務と配置

## 適用条件
文章に残す情報の配置が、次のいずれかに左右される場合に使う。

- 成果物または節の責務境界。
- 内容を決定または更新する主体と変更契機。
- 適用範囲と寿命。
- 正本と派生の関係。
- 正本への参照、または記述移動に伴う責務の変更。

読者の理解順序、文章の進行、節が答える問いによって決まる成果物内の配置は、[文章構造](lens-document-structure.md) で判断する。

## Phase 1: 配置する情報を分ける
配置対象を、一つの命題と一つの役割の組み合わせへ分ける。

| 情報の役割 | 内容 |
| --- | --- |
| 定義、要求、規則、制約 | 対象について現在有効な内容を定める。 |
| 理由、判断根拠 | 採用した内容を選んだ理由を説明または記録する。 |
| 手順、利用方法 | 正本の内容を特定の作業や判断で利用する。 |
| 説明、例 | 正本の理解を助ける。 |
| 観測、進捗、履歴 | 特定時点の状態または変化を記録する。 |

同じ文に複数の役割、適用範囲、版、時点、変更主体が含まれる場合は、独立して配置を判断できる単位へ分ける。
根拠化結果または指示対象の対応がある場合は、根拠の組み合わせ、採用状態、情報状態、合成された適用範囲、再評価条件、具体対象、責任主体、条件、関係を各単位へ引き継ぐ。
複合命題の構成要件、前提、適用範囲が別々の情報源によって定まる場合は、正本を判断できる情報単位へ分ける。各構成単位の正本と、根拠化結果が示す根拠の組み合わせを複合命題へ対応付ける。

## Phase 2: 候補となる成果物の責務を確認する
配置を変更できる範囲にある既存の成果物と節を確認する。候補ごとに対象と役割、および読者の利用目的を確認する。
決定・更新主体、変更契機、適用範囲と寿命、正本と派生、参照関係は、候補を区別する場合、情報が独立して管理または変化する場合、または責務境界が未確定な場合に、配置判断へ必要な項目を確認する。

| 項目 | 確認内容 |
| --- | --- |
| 対象と役割 | 何について、何を定め、説明し、利用し、または記録するか。 |
| 読者の利用目的 | 誰が、どの判断または行動に使うか。 |
| 決定・更新主体 | 誰が内容を決定し、誰が更新するか。 |
| 変更契機 | 仕様変更、計画変更、運用変更、観測、時間経過など、何によって変わるか。 |
| 適用範囲と寿命 | 対象、条件、版、期間、環境と、いつまで有効か。 |
| 正本と派生の関係 | この成果物が内容を定めるか、別の正本を説明または利用するか。 |
| 参照関係 | どこから参照され、どの正本を参照するか。 |

責務は、利用者またはプロジェクトの指示、成果物自身の目的と契約、テンプレート、同種成果物の一貫した構造、既存の参照関係の順に確認する。
名称、ディレクトリ、話題の近さは候補の探索に使い、責務の確定には上記の契約を使う。

## Phase 3: 成果物との関係を決める
各情報単位と候補成果物の関係を、次のいずれかへ割り当てる。

| 関係 | 配置する内容 |
| --- | --- |
| `正本` | その情報を現在有効な内容として定める。 |
| `固有説明` | その成果物の読者と利用目的に固有の説明、影響、解釈を置く。 |
| `利用` | 正本を使う手順、操作、判断方法を置く。 |
| `記録` | 判断理由、観測、進捗、履歴を、その時点と範囲を伴って置く。 |
| `参照` | 正本または詳細を示す参照だけを置く。 |
| `省略` | 成果物の責務と読者の利用目的に必要な役割がないため、文章へ置かない。 |
| `確認待ち` | 責務、正本、権限、範囲を確定する情報を確認事項として残す。 |

`正本` は、Phase 1 で分けた一つの情報単位の同じ意味、適用範囲、版について一つに定める。複合命題の成立を複数の情報単位が定める場合は、各単位の正本と、根拠化結果で確定した根拠の組み合わせを保持する。次の順に候補を評価する。

1. 既存の正本契約。
2. 内容を決定または更新する権限。
3. 情報の変更契機、適用範囲、寿命との一致。
4. 読者が行う判断または行動との一致。
5. ほかの成果物から安定して参照できること。

一つの候補がすべての必要条件を満たす場合に配置を確定する。
候補がない場合は、新しい成果物または責務の候補を示し、作成権限に応じて作成または確認待ちとする。
複数の候補が同じ条件を満たす場合は、重なる責務と正本の選択に必要な判断を確認待ちとする。
確定した情報単位の配置は進め、確認待ちの情報単位は現在の配置または変更前の状態を保持する。
外部の正本や実行時状態が値を定める場合、文章には利用目的に必要な説明、取得・更新・評価方法、適用範囲を置き、外部の正本を参照する。

## Phase 4: 責務上の配置先を確定する
成果物内の節が独立した責務、決定・更新主体、適用範囲、寿命、または正本と派生の関係を持つ場合は、情報単位と同じ境界を持つ節へ配置する。
読者導線と節が答える問いだけで区別する成果物内の節配置は、[文章構造](lens-document-structure.md) へ渡す。
必要な責務境界を受ける既存の成果物または節がない場合は、新しい責務単位の候補を示し、作成権限に応じて作成または確認待ちとする。

## Phase 5: 移動と参照を整える
記述を移動、統合、分割した場合は、次を同じ変更で更新する。

- 旧配置に残る正本または重複した説明。
- 移動先と移動元を参照する成果物。
- 前後の節で使っている前提、用語、導線。
- 正本の変更によって役割が変わる説明、手順、履歴。

非正本の成果物には、その成果物に固有の説明または利用方法と、解決可能な正本への参照を置く。

## 成果と完了条件
配置判断は作業上の中間成果である。利用者が配置表を求めた場合を除き、判断結果を使って文章を作成または変更し、配置表自体は完成文へ残さない。

- 各情報単位が、`正本 / 固有説明 / 利用 / 記録 / 参照 / 省略 / 確認待ち` のいずれかに対応している。
- 各配置を、成果物と節の責務、読者の利用目的、および配置を左右した決定・更新主体、変更契機、適用範囲へ追跡できる。
- 配置を確定した各情報単位について、同じ意味、適用範囲、版を定める正本が一つである。
- 複合命題を、構成単位ごとの正本と根拠の組み合わせへ追跡できる。
- 配置判断を変える合成された適用範囲と再評価条件が、情報単位と配置先の責務に保持されている。
- 非正本の記述が、その成果物に固有の役割と正本への参照を持つ。
- 移動後の旧配置、参照、前後の文脈が、確定した責務と一致している。
- 責務または正本を確定できない情報が、必要な確認事項とともに確認待ちへ分かれている。
