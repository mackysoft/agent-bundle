# writing

## 目的
自然言語の文章を、文章前提に従って作成、変更、レビューする。
意味保持と事実性を守り、論理構造、文章構造、媒体に合う文体、言語ごとの表記を整える。
内容の権威、更新、寿命、正本と派生、責任境界が配置を左右する場合は、それらを確定して責務に対応する場所へ配置する。
高品質な文章とは、読者が内容を正確に理解し、根拠に沿って判断し、必要な行動を特定できる文章である。

## 文章前提
文章を作る前に、必要な範囲で文章前提を固定する。

| 項目 | 判断 |
| --- | --- |
| 作業種別 | 作成、変更、推敲、レビュー、要約、短縮、翻訳、ローカライズ、返信のどれか。 |
| 対象 | 何について書くか。 |
| 読者 | 誰が読み、どの文脈を共有しており、何を判断または実行するか。 |
| 共有範囲 | 誰に届き、どの情報を共有できるか。 |
| 媒体 | 会話、スレッド、返信、コメント、メール、案内、告知、提案、報告、説明文、記事、原稿、仕様、マニュアルなどのどれか。 |
| 利用可能な表現 | 最終掲載先で正しく表示、利用できる見出し、表、図、コードブロック、画像などの表現。 |
| 成果物の責務 | 対象成果物が何を定め、説明し、利用し、記録するか、および読者のどの判断または行動に使われるか。配置先の責務境界を判断する場合は候補ごとに確認する。 |
| 正本と更新 | 内容の権威、更新、寿命、正本と派生の関係が文章の内容または配置を左右する場合に、決定・更新主体、変更契機、適用範囲を確認する。 |
| 言語 | どの言語で書くか。 |
| 出力形式 | 完成文、要約、レビュー結果、差分案、確認事項などのどれか。 |
| 意味保持 | 元文の事実、主張、条件、責任主体、時制、確度をどこまで保つか。 |

ユーザー指定、作成先、既存の文章、テンプレート、同種の文章の順に根拠として使う。
言語が未指定の場合は、作成先または更新先の既存の文章、同じ場にある同種の文章、公開対象、会話言語の順に判断する。
確認済みの意味、事実、命題の状態と適用範囲、情報の役割、責任主体、成果物の責務、正本関係を保持できる表現上の判断は、合理的な仮定を置いて進める。
これらを確定または変更する判断に根拠が不足する場合は、確認が必要なことと、今回はどう扱ったかを分ける。

## 情報の選別
依頼、会話、既存の文章、参照資料に含まれる情報は、成果物における役割を区別して扱う。

| 役割 | 扱い |
| --- | --- |
| 作業を決める情報 | 内容の選択、構造、表現、変更方法に反映する。 |
| 読者へ伝える情報 | 文章前提に照らし、必要な範囲を成果物へ残す。 |

同じ情報が両方の役割を持つ場合は、それぞれに必要な部分を分けて扱う。
背景、根拠、経緯は、読者の理解や判断に必要で、共有範囲に含まれる場合だけ成果物へ残す。

## 優先順位
1. 確認済みの事実、意味保持、責任主体、条件、不確実性を守る。
2. 文章前提を優先する。
3. 媒体で利用できる構造、表現、粒度にする。
4. 言語ごとの自然な表記、語法、強調へ整える。
5. 簡潔さ、読みやすさ、文章のリズム、語感を調整する。

## 流れ
作業の規模と影響に応じて、必要な判断だけを行う。

### 軽量経路
利用者が変更対象、配置先、編集目的、保持する意味上の不変条件を特定し、確認済みの意味、責任主体、配置、参照関係を保持できる変更は、必要な文章参照を使って変更し、共通の自己点検を変更の影響が届く範囲で行って完了する。
新しい命題状態、命題間の関係、対象対応、成果物責務、正本関係の判断が生じた場合は通常経路へ移る。

### 通常経路
1. 利用目的を判断できる文章前提として、作業種別、対象、読者、媒体、出力形式、意味保持の範囲と、読者が行う判断または行動を確認する。既存の成果物では、指定対象と周辺構造、利用先を確認する。内容の権威、更新、寿命、正本と派生、責任境界が作業によって変わる場合は、候補となる成果物と節、その決定・更新主体、変更契機、適用範囲、参照関係を追加で確認する。
2. 確認済みの命題は、`$claim-grounding` の成果契約のうち文章判断を変える項目を文章前提へ直接使う。文章化に必要な根拠化結果を同じ契約で入力から直接構成できない場合は、文章構造を決める前に `$claim-grounding` を適用する。
3. 利用者が指定した名称と対応、および確認済みの意味で使う確立した語は、その対応を使う。確認済みの対象と確立した語から作れる見出しと要約ラベルは、文章構造の判断として扱う。新しい名称、分類、抽象化が複数の対象または役割を覆う可能性があり、その曖昧さが意味、責任主体、成立条件、関係、成果物の責務を変える場合、または既存名称の対応を意味上見直す場合は、本文構造と名称を決める前に `$referent-modeling` を適用する。
4. 内容の配置が、成果物または節の責務境界、決定・更新主体、変更契機、適用範囲と寿命、正本と派生、参照関係の判断を伴う場合は、文章構造を決める前に [references/task-content-placement.md](references/task-content-placement.md) を適用する。一つの成果物内で、読者の理解順序と節が答える問いに沿って配置する場合は [references/lens-document-structure.md](references/lens-document-structure.md) を使う。
5. 確定した対応、配置、根拠から残りの文章前提を決め、成果物に残す情報と参照を選ぶ。根拠化結果がある場合は、根拠の役割を含め、文章判断を変える項目を `$claim-grounding` の成果契約どおりに保持する。指示対象の対応がある場合は、文章判断を変える項目を `$referent-modeling` の成果契約どおりに保持する。その上で、成果物の責務に対応する内容を選ぶ。
6. 文章前提と判断基準に従い、求められた作業を行う。
7. 文章全体を点検し、問題があれば該当する判断を見直して直す。

## 基本規則
- 記述の確度と断定の強さを、確認できた根拠に合わせる。
- 意味保持が必要な作業では、事実、主張、条件、責任主体、時制、確度を保持する。
- 簡潔化や文体調整の後も、読者に必要な定義、条件、根拠、制約、不確実性を保持する。
- 現在有効な契約、状態、要求を肯定形で一意に示せる場合は、その内容を直接書く。
- 否定や対比は、禁止または除外そのものを定める、根拠から合理的に生じる誤読を解く、旧契約からの移行を説明する、または明示された対立命題へ応答する役割で使う。対象となる命題は、入力または根拠から特定する。
- 各記述には、結論、根拠、条件、案内など、成果物内で果たす役割を持たせる。
- 各記述は、その内容を定め、説明し、利用し、または記録する役割に沿ってまとめる。内容の権威、更新、寿命、正本と派生、責任境界を判断した場合は、その責務を持つ成果物へ置く。
- 正本を定める場合は、独立して正本を判断できる一つの情報単位について、同じ意味、適用範囲、版を担う正本を一つにする。複合命題は構成単位ごとの正本と、根拠化結果が示す組み合わせを保持する。
- 根拠化結果を文章化する場合は、根拠の役割を含め、成果物の責務に必要な項目を根拠化結果と一致させる。
- 外部の正本や実行時の状態から決まる情報は、根拠化結果が示す適用範囲、評価時点、確度、再評価条件、更新または評価方法を必要な範囲で表現する。固定した観測は、評価時点を伴う記録として扱う。
- 範囲、条件、制約は、読者が利用できる現在有効な内容として直接記述する。
- 作成過程や候補案は、読者の判断に必要な材料として整理できる場合に残す。
- 変更では、現在有効な内容を文章へ反映し、役割を失った記述を置換、統合、削除する。
- 既存の文章を変更するときは、見出し階層、用語、表記、粒度を既存文書と整合させる。
- 選択した参照の判断基準を満たす。

## 自己点検
出力前に、必要な観点だけを確認する。

- 事実、主張、条件、責任主体、確度が、根拠および元の文章と一致しているか。
- 主張、根拠、因果、例の対応を追えるか。
- 読者が目的、必要な情報、判断と文章の進行を追え、行動が必要な場合はその内容を特定できる構造になっているか。
- 媒体で利用できる表現を使い、言語に合う粒度、表記、文体になっているか。
- 成果物に残したすべての記述が、読者にとって必要な役割を持ち、共有範囲に含まれているか。
- 肯定形で成立する記述は、現在有効な内容を直接示しているか。
- 否定や対比には、禁止、除外、誤読の解消、移行、対立命題への応答のいずれかの役割と、根拠から特定した対象があるか。
- 作業を決める情報、作成過程、候補案を残す場合は、読者の判断材料としての役割が明確か。
- 変更箇所、前後の段落、属する節、および同じ内容を参照または反復する箇所が、変更の影響が届く範囲で整合しているか。

内容の責務と配置を判断した場合:

- 各情報単位の配置、移動後の旧配置、参照、前後の文脈が、[references/task-content-placement.md](references/task-content-placement.md) の完了条件を満たしているか。
- 複合命題の構成単位ごとの正本と、根拠の組み合わせを追えるか。

根拠化結果を文章化した場合:

- 文章に使った命題とその扱いが、根拠の役割を含む、文章判断を変えた根拠化結果の各項目と一致しているか。
- 可変情報が、その値を定める正本と更新または評価方法へ対応しているか。

## 出力
完成文を求められている場合は、完成文を先に返す。
他のスキルを下位能力として適用した場合は、その作業結果を文章判断へ使い、利用者向け出力には依頼された成果物と必要な確認事項を含める。利用者が下位能力の成果も求めた場合は、指定された範囲を併せて返す。
既存の文章の変更を求められている場合は、変更後の文章または差分案を返す。
文章のレビューを求められている場合は、問題、理由、修正方向を返す。
推敲前後の比較が必要な場合だけ、変更前後を並べる。
判断が必要な点が残る場合は、確認が必要なことと、今回はどう扱ったかを分けて返す。
